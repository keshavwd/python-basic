# Python Basic Learning

This repository documents my journey of learning **Python fundamentals** through practical exercises, conditional logic, and loop-based problems.  
It contains beginner-friendly programs, practice PDFs, and examples that cover core concepts like operators, strings, data types, conditionals, and loops.

---

## 📂 Project Contents

### Practice PDFs
- **Basic_Programming_Questions.pdf** → Collection of introductory Python problems (variables, operators, conditions).
- **if_else_exercie.pdf** → Exercises focused on conditional logic (`if`, `elif`, `else`).
- **For_Loop_Exercise.pdf** → Loop-based problems including star patterns and number sequences.
- **Guess_Output.pdf** → Output-prediction exercises to strengthen understanding of Python execution flow.

### Example Programs
- **Day & Month Programs**  
  - Print day name using day number (1–7).  
  - Print month name using month number (1–12).  

- **Character Handling**  
  - Check if a character is a vowel or consonant.  
  - Print ASCII/Unicode value of a character.  
  - Identify special characters using ASCII ranges.  
  - String capitalization methods (`capitalize`, `title`, `upper`, `lower`).  

- **Conditional Logic**  
  - Loan eligibility check (age, salary, credit score).  
  - Student pass condition (all subjects ≥ 40 and average ≥ 50).  
  - Discount percentage based on purchase amount.  
  - Input range validation.  

- **Geometry Programs**  
  - Area and type check for triangles (isosceles, equilateral, scalene).  

- **Loop Patterns**  
  - Pyramid star pattern.  
  - Other loop-based exercises from `For_Loop_Exercise.pdf`.

## 🎯 Learning Goals
- Master Python fundamentals: variables, operators, data types, strings.
